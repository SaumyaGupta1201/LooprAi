# Loopr Finance — Frontend

React + TypeScript + Vite client for the Loopr Finance dashboard.

See the [project root README](../README.md) for full setup instructions,
and [API_DOCS.md](../API_DOCS.md) for the backend API reference.

## Quick start

```bash
npm install
npm run dev
```

Requires `VITE_API_URL` set in `.env` — see the root README.
